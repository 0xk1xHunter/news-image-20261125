A one-image summary of the world news of Wednesday 25 November 2026. The
poster is a newspaper front page drawn entirely in code with PIL: a masthead
reading "THE WORLD TODAY", the date, and six story panels covering the
Ukraine strikes on Russian ships, the collapse of COP31, the Houthi strike
on Riyadh, the Huawei conviction, Microsoft's "Code Red" outage, and the
Shenzhou-24 launch. No network, no image assets, no photographs — every
pictogram is a set of shapes drawn by `draw.py`, and running the program
twice produces byte-identical output.

## Run it

```
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
